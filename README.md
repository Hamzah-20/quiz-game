# Overview

**Live Project Repository:**  
https://github.com/Hamzah-20/quiz-game

Quiz Game is a lightweight web-based quiz application designed to provide an interactive question-and-answer experience.

The application allows users to:
- Answer quiz questions interactively
- Receive instant feedback
- Track scores dynamically
- Navigate through quiz rounds
- Experience a responsive frontend interface

This project demonstrates:
- Frontend web development fundamentals
- JavaScript DOM manipulation
- Dynamic UI updates
- Event handling
- Interactive game logic
